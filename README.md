# RailSI Translate

Русский ⇄ словенский перевод через DeepL Free API. Требуется Node.js 22.9+.

## Запуск

Задайте DEEPL_API_KEY в серверном .env и выполните `npm start`.
Откройте http://localhost:3000. Ключ не включается в публичные файлы или ответы API.

POST /api/translate принимает JSON с text, sourceLang и targetLang (RU → SL или SL → RU).
Backend вызывает https://api-free.deepl.com/v2/translate с Authorization: DeepL-Auth-Key и явными source_lang/target_lang.
Текст передаётся без изменений, результат возвращается без постобработки. Ответ содержит translation, provider: DeepL и deepLStatus.
Ошибка DeepL прекращает перевод и возвращается пользователю. Без ключа возвращается HTTP 503.
GET /api/health показывает наличие серверной настройки без секрета.

Дизайн, темы, SVG, анимации, адаптивность, голосовой ввод, озвучка и PWA сохранены.
История хранится локально до 50 записей. Офлайн можно просматривать историю, словарь и фразы; новые переводы требуют сети.
Выбор словаря или фразы запускает реальный запрос DeepL. Service worker не кеширует API.

## Проверки

`npm run check` и `npm test`.
Контрактные тесты проверяют точную передачу текста, оба направления, ошибки и защиту ключа.
Реальные запросы выполняются через запущенный backend с ключом из .env.

## Размещение

На Vercel публичная папка — `pwa`; `api/health.js` и `api/translate.js` используют общий обработчик `server/api.js`. Серверная переменная `DEEPL_API_KEY` задаётся в Vercel для Production. `vercel.json` задаёт маршруты функций, таймаут и заголовки. Service worker не кеширует API и обновляет публичные ресурсы из сети.

Локально используется постоянный Node.js процесс; HOST и PORT задаются на сервере.
API ограничивает запросы до 30 в минуту на IP соединения, текст до 5000 символов, тело до 40 KB.
Таймаут DeepL — 30 секунд. За reverse proxy настройте ограничение запросов на уровне прокси.
